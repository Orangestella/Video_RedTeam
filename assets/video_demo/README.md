# README Video Demo Assets

Place the README demo videos in this directory with the following filenames:

- `case1_original.mp4`
- `case1_rewritten.mp4`
- `case2_original.mp4`
- `case2_rewritten.mp4`

The root `README.md` uses the following GIF previews for GitHub-compatible display:

- `case1_original.gif`
- `case1_rewritten.gif`
- `case2_original.gif`
- `case2_rewritten.gif`

Each GIF is linked to its corresponding MP4 file in the README.
